# Hostel-Booking-Management-System-Using-Sql


Summary
The objective of this MS SQL project is to design and implement a database system that effectively manages hostel bookings. This database will be tailored to support a hostel booking system with structured data organization, streamlined CRUD (Create, Read, Update, Delete) operations, and views that facilitate comprehensive data analysis and management. The proposed project will demonstrate the database with primary keys, foreign keys, and relational database concepts.

Project Scope
The project scope includes the following components:
•	Database Design: Development of a relational database with tables capturing critical data points in hostel bookings.
•	Table Structures: Creation of tables with primary and foreign keys to ensure data integrity and efficient querying.
•	CRUD Operations: Implementation of CRUD queries to manage records effectively.
•	Views: Definition of views for easy data retrieval and generation of reports.
•	

Key Functional Requirements
•	Hostel Management: Store details for each hostel, including name, location, and owner details.
•	User Management: Track user types (e.g., hostel admin, students) and details for all users, with associated booking and ownership histories.
•	Room and Facility Management: Define room categories, facilities, and room details.
•	Booking Tracking: Enable tracking of room bookings done by students.
•	User Feedback: Collect and store feedback from users.



Database Structure
The database will consist of the following tables:
1.	Hostels: Contains hostel details such as name, address, and general information.
2.	User Type: Stores different roles (e.g., hostel admin, students) within the system.
3.	Users: Tracks user data including contact information and assigned user type.
4.	Rooms: Defines individual rooms with relevant details such as room type and rates.
5.	Room Facilities: Specifies the facilities available in each room, linked to Rooms.
6.	Room Type: Categorizes room options (e.g., single, double, dormitory).
7.	Room Booking: Records booking details, including user, room booked.
8.	Room Availability: Manages availability status of rooms on specific dates.
9.	Amenities: Lists amenities (Wi-Fi, parking) available per hostel.
10.	Feedback/Reviews: Stores user feedback on hostels to enhance user experience
